## ✦ The Anti-Gravity Philosophy

This project abandons standard DOM structures to create an immersive, application-level experience. Every interaction is governed by algorithmic precision and fluid physics.

* **OLED Cosmic Canvas:** Pure `#000000` backgrounds combined with shifting aurora mesh gradients and an SVG grain texture for a tactile, premium feel.
* **Spatial Glassmorphism:** Core terminals utilize heavy `backdrop-filter: blur(32px)` with dynamic ambient lighting that reacts to cursor coordinates.
* **Fluid macOS-Style Dock:** A floating, physics-driven bottom navigation dock featuring 3D icons, bounce-up magnification, and frosted glass tooltips.
* **Engineered Typography:** **Space Grotesk** for cinematic headers (rendered at massive 7rem scales) and **JetBrains Mono** for all inputs and data.
* **Hyper-Microinteractions:** Liquid CSS transitions, magnetic button pulls, OTP haptic visual feedback, and a <kbd>⌘</kbd> + <kbd>K</kbd> global command palette.

## ✦ Quick Start Initialization

**1. Clone the environment**

```bash
git clone https://github.com/shyam_444/bharatsetu-antigravity.git
cd bharatsetu-antigravity

```

**2. Install dependencies**

```bash
npm install

```

**3. Configure environment variables**
Create a `.env.local` file at the root to establish secure backend links.

```env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
NEXT_PUBLIC_NLP_MODEL_PATH=/models/indic-whisper.onnx

```

**4. Ignite the development server**

```bash
npm run dev

```

*Navigate to `http://localhost:3000` to interface with the Anti-Gravity portal.*
